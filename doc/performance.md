## 縮圖工作區

- 虛擬網格只掛載可視列及前後兩列，保留「載入更多／全部載入」與跨捲動選取。
- 前端縮圖 LRU 同時限制 200 筆及 16 MiB（依 UTF-16 字串長度保守估計）；未開始的離屏請求直接移除，最多同時 3 個後端請求。
- 後端縮圖直接串流解碼，只暫存讀取尺寸所需的前綴；同時解碼的總像素不超過 5,000 萬。
- 磁碟縮圖使用 LRU 索引；每次寫入維持最多 1,200 筆、256 MiB，只在初始化掃描目錄。外部刪除快取時同步移除索引。
- 縮圖版本包含來源大小與修改時間；macOS 另比對 inode 與 change time。解碼期間來源變更時不寫入舊版本快取；快取讀取在同一 FD 上限制最多 16 MiB。
- 影音解壓及轉檔快取比對來源檔案識別、大小、修改時間；來源更新時重建，已開啟的舊讀取器仍可完成讀取。
- 媒體清理先取消準備與複製，再等待項目鎖釋放；HTTP 只持鎖至成功開檔，串流讀取不占用準備鎖。
- 像素預算不是程序 RSS 上限：解碼器工作區、16-bit 圖片及 GC 尚未回收的物件仍會占用記憶體。仍使用 Go 完整解碼，尚未加入平台限定的降採樣解碼器。

## 主圖傳輸

`LoadImage*` 的 `ImagePayload.dataUri` 可為 `/image/<id>?v=...` 本機網址。保留欄位名稱以維持前端結構；不要假設一定是 Base64。

本機圖片由 HTTP 串流傳輸，保留 128 MiB 檔案與 5,000 萬像素限制，GET／HEAD／Range 與 ETag。端點只接受已註冊的圖片 ID。壓縮檔圖片仍有完整驗證緩衝區，最多並行 2 筆；原圖不再經由 Wails 傳輸 Base64。

前端只解碼目前顯示的圖片，切圖取消舊要求，背景僅預備相鄰圖片的網址／標頭。剪貼簿仍可輸出 PNG，只有文字備援時才轉回 Data URI。

## 壓縮檔

- ZIP：LRU 最多 4 個中央目錄索引；每個最多 20,000 個項目與約 8 MiB 的標頭資料估計值。超限時不保留索引。
- TAR／TGZ：最多 2 份、每份最多 256 MiB 的私有暫存內容與 20,000 個索引項目。第一次讀取建立索引會多花時間與磁碟 I/O，後續以位移讀取；超限或稀疏檔案回到原串流方式。暫存檔不依壓縮檔中的路徑解壓至目錄。
- 大小、修改時間或檔案識別改變時快取失效；清空圖庫及結束應用程式會清理快取。使用中的 reader 關閉後才釋放其資源。

## 圖庫

展開狀態與選取獨立儲存，不觸發整棵樹的 JSON 寫入。掃描約每 100 ms 批次更新畫面，同批結果只遍歷一次樹；未變更分支保留原參考。忽略未支援的檔案時不額外取得檔案資訊。

## 2026-10-03（第二輪）：掃描佇列、工作區篩選及小型讀取

本輪繼續保留 UI、操作、功能與認證方式，沿用上一輪修改。

- 目錄掃描改為優先／一般兩個 FIFO 佇列，路徑只分類一次，避免每次加入子目錄後重新排序全部待掃描路徑。以固定 256 筆的分塊保存，取出後清除該路徑參照，清空的區塊可回收。Finder 指定路徑仍優先，各群組順序、進度與取消檢查維持不變。
- 工作區無篩選時直接複製清單，保留每次篩選結果的新陣列身分；搜尋改為欄位逐一短路比較，不建立每筆欄位陣列，也不保存持久搜尋字串快取。
- 零選取時不再建立整個圖庫的有效 ID 集合；非空選取只保留與選取相交的 ID。範圍／全選不先建立中間 ID 陣列，批次刪除以集合查詢取代逐筆 includes，保留選取插入順序及部分失敗行為。
- CSV／TSV 使用重用的語系比較器，保留原有數字優先及自然排序。沒有排序的搜尋只保留前 1,000 筆，在第 1,001 筆符合時顯示原本的截斷提示；需要排序時仍處理全部匹配列。已由篩選產生的新陣列可直接排序，避免額外複製。
- 後端在大小提示為 1 MiB 以下時預配置讀取緩衝。提示只影響容量，不決定讀取長度；仍完整讀至 EOF，保留大小哨兵、ZIP CRC、取消與檔案大小失準處理。未知或較大提示使用原有標準讀取方式，避免預先配置大量記憶體。

## 2026-10-03（第一輪）：減少重複遍歷與暫時配置

本次維持 UI、操作、功能、格式支援及安全限制；只調整內部資料整理與工作區重用。

- 圖庫更新採延遲複製，未變動的 images／children 不建立替代陣列；批次搬移只遍歷一次樹，每個目的地排序一次。成功／失敗回報、選取清理及同名穩定排序保持原有語義。
- 顯示樹保留未變動分支，WeakMap 快取可見節點與分類統計。節點更新必須維持 immutable；快取以弱鍵保存，不阻止已丟棄樹被 GC 回收。
- 工作區維持根節點優先的順序，導覽維持子節點優先的順序。收集結果直接追加，不再每層複製整份子樹陣列；根目錄清單共用既有結果。
- 摺疊節點的選取標記一次檢查所有選取 ID。圖片預取仍依 +1、−1、+2、−2 的圖片順序，只收集附近項目，不再每次切圖建立完整導覽與篩選陣列。
- 檔名排序直接比較小寫 rune，避免每次比較建立兩個小寫字串；保持 strings.ToLower 的 Unicode、無效 UTF-8 與穩定排序行為。
- 重複內容偵測以輸入下標保存候選，只有相同大小時才建立候選陣列；同次操作共用 32 KiB 雜湊讀取緩衝，確認重複後才建立回傳項目。
- 磁碟縮圖快取命中時移動原 LRU 節點，更新大小差額，不再移除後重新配置節點。PNG 壓縮工作區可重用；使用後清除縮圖像素與輸出 buffer 的參照，閒置工作區仍可由 GC 回收。原圖已符合縮圖尺寸時直接複製，省去雙線性縮放的中間陣列；代表性像素格式的 PNG 輸出與原流程逐 byte 相同。
